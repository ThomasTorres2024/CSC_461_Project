# CSC 461/DSP 461 Project URI
Analysis of the LocalMAP dimension reduction algorithm and replication of figures from the LocalMAP paper.
All of the code in this codebase is intended to work in a Google Colab environment and nowhere else.

# Replication
When using any of this code be sure to download the "data.zip" folder. The code will not work otherwise. 
There may be other zipped files in here - unzip them at run time. There may also be "fmnist_images.npy" rename it to "fmnist.npy". 
There may be "mnist_images.npy", rename it to "mnist.npy".

Replicated figures and associated code can be found under the Recreation directory. Everything there should be enough to see what we used to replicate our figures. 

# Eigenfaces
Results for the Eigen Faces and associated code can be found under the Eigen Faces directory. There are more figures there as well for different iterations that added more eigen-vectors.
